- `mantik-blog-compiled.txt` — Single-file chronological/alphabetical plain-text compilation of all 23 articles.
- `MANIFEST.sha256` — Cryptographic SHA-256 checksums for every file in the archive.
- `LICENSE.md` — Original repository license.
