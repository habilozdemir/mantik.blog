# Mantık Blog Digital Archive (`mantik.blog`)

Permanent, SHA-256 verified digital archive of 23 Turkish essays on classical Aristotelian logic, categorical syllogisms, conversion, obversion, logical equivalences, and fallacies.

## Contents
- `articles/` — Original Markdown files for all 23 essays (with full 70-commit Git history preserved).
- `mantik-blog-compiled.txt` — Single-file plain-text compilation of all 23 essays.
- `MANIFEST.sha256` — Cryptographic SHA-256 checksums for every file in the archive.
- `LICENSE.md` — Original repository license.
